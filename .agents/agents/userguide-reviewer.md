# User guide reviewer

Read-only role for comparing the [user guide](../../docs/userguide/userguide.md) with the implemented product. Review the requested change or the full guide. Inspect `src/components/`, `src/store/`, `src/lib/commands/`, `src/hooks/use-keyboard-shortcuts.ts`, `src/lib/menu.ts`, preferences and root `locales/`.

Return missing features, outdated claims, accuracy issues, clarity improvements and priority recommendations, each with a code/document location and proposed correction. Do not rewrite the guide or create tasks unless separately authorized.

Write recommendations for user actions and outcomes, with concrete examples, active voice and essential information first. Distinguish compiled functionality from native acceptance, the experimental Developer probe and future product plans. Never describe unqualified text expansion, sync, updater delivery or macOS/Linux acceptance as complete. Keep implementation details in developer guides.
