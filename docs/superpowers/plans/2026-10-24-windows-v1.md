# Windows v1 Prototype Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver Ampello's Windows feature set in Texpio's existing UI, starting with working expansion.

**Architecture:** Independent Windows product engine alongside the retained strict Developer probe. Rust owns settings, snapshots, effects, SQLite and files; typed services/TanStack Query expose management to the existing shell.

**Tech Stack:** Tauri 2, React/TypeScript, shadcn/Radix, Bun 1.4.4, Node 24.18.0, Rust 1.99.1, windows 0.62.2, bundled SQLite.

**Spec:** [Windows v1 design](../specs/2026-10-24-windows-v1-design.md). Execution base `84fefd6449cc66503da6bcd3fc70de5a10099be0`; Native/current checkout and autonomous execution preserved.

## Global constraints

- Windows only; no backend/sync/accounts or macOS/Linux implementation.
- Preserve current UI/layout/theme/locales. All visible copy en/fr/ar. No upstream runtime code copied.
- No global hooks/input in ordinary tests. Native fixture checks explicitly opted into and bounded.
- Keep strict Developer/P0 unchanged and distinguish submitted product effects from observed exact output.
- Never compensate/replay partial input. Preserve newer clipboard copies and refuse held modifiers/changed targets.
- Use immutable snapshots and bounded queues, no raw input/body/path logs. Regenerate bindings for changed commands.
- Keep data migration/backups/revision conflicts and selected-file scopes; no broad filesystem permissions.
- Pin any genuinely needed added dependencies; retain existing tool/dependency pins and verify frozen installs.

## Review focus

- An old pending job must not run after Stop, library switch or settings change (tasks 2/5).
- Keyboard cancellation/focus change after deleting a trigger must stop output without typing a compensating terminator (task 2).
- Clipboard restore must not overwrite a user copy made during paste, including failure paths (task 2).
- Archive import must reject traversal/collisions/bombs before altering a library (task 6).
- Shared-library refresh and usage updates must preserve editor drafts and revision correctness (tasks 4/5/7).

## Tasks

### Task 1: Product matching and settings contracts

**Files:** Create `src-tauri/src/product/{mod,settings,matcher}.rs`; register `pub mod product` in `lib.rs`.

**Interfaces:** `ProductSettings` (boundary, terminator, insertion, restore, speed, cancel, clipboard mode/shortcut, autostart, close-to-tray, attachment delay); `ProductRule { id, trigger, body }`; `TypedHistory::new(Vec<ProductRule>, Boundary)`; `push(char) -> Option<Expansion>`; `backspace/reset`; `Expansion { rule, terminator }`. No OS calls.

- [ ] Write failing unit cases: longest suffix, word/anywhere, colon and existing semicolon triggers, punctuation/Space/Tab/Enter, Unicode, Backspace, resets, empty body and disabled rules excluded by caller. Assert no match in embedded word by default.
- [ ] Run `cargo test --locked --manifest-path src-tauri/Cargo.toml product::matcher` and observe missing behavior.
- [ ] Implement bounded character history/suffix matching and validated enums/default settings; default Paste, balanced 300 events/sec, Escape, terminator/restore on, no automatic startup hook.
- [ ] Run focused tests and record RED/GREEN; commit working pure core.

### Task 2: Windows product service and effects

**Files:** Create `src-tauri/src/product/{windows,effects,clipboard}.rs`, update `Cargo.toml` only to enable required existing Windows binding features; explicit example `product_native_trial.rs`.

**Interfaces:** `ProductEngine::new`, `start(rules, settings) -> Result<ProductStatus, ProductError>`, `stop`, `status`, `replace_snapshot`; `ProductStatus { phase, submitted, cancelled, last_error }`. `EffectBackend` supports target checks, erase, text/paste and cancellation. Windows module owns hook/message thread and worker; core service may be tested with a fake effect backend without hooks.

- [ ] Write failing effect state-machine tests for cancelled generation, target change, partial send, modifier refusal, no retry, and clipboard sequence ownership. Write native-independent tests for UTF-16 scalar event grouping and line/tab semantics.
- [ ] Run focused tests, implement prepare-before-delete and bounded paced sends, explicit Paste/Type, one backend selected before mutation; record partial effects precisely.
- [ ] Implement hook translation with foreground layout/no dead-key mutation, own-origin markers, reset on mouse/navigation/focus/layout, bounded queued jobs and exact thread cleanup. Suppress matched terminator only if a job was accepted.
- [ ] Implement native clipboard snapshot/write/sequence-aware restore and file-ready payload abstraction; no silent fallback. Add an explicit deadline-bound trial helper restricted to a task-owned fixture, not ordinary tests.
- [ ] Run core tests/Clippy and one synthetic product fixture; observe exact output separately and stop on uncertainty. Commit engine path after evidence; do not claim physical campaign.

## Self-review

Every feature family in the design maps to tasks 1–8; task 9 owns final validation. Matching/settings precede native effects and IPC. Metadata precedes files/location/backups/dashboard. Prototype progress does not imply the strict P0 physical campaign or other OS adapters are complete. Unknown native outcomes stop the affected experiment while independent feature work continues.
