# Texpio preview guide

Texpio is an early preview. Everyday text expansion and the snippet library/editor are future milestones. Home provides the application shell; Developer contains the experimental Windows probe.

## Find actions and customize

Open the command palette from the app menu or its displayed shortcut. Search for actions, toggle/resize sidebars and switch Home/Developer. Layout saves locally.

Preferences offers System/Light/Dark and English/French/Arabic. System follows OS appearance; Arabic changes direction. Choices persist natively and apply to the quick pane. Failed loading shows Retry without discarding saved settings.

## Quick entry

Press Control+Shift+Period on Windows/Linux or Command+Shift+Period on macOS. Rebind/reset in Preferences. A conflicting chord preserves the previous binding and shows an error.

Enter sends one explicit entry to main. Escape or clicking away cancels and clears it. Entry stays transient and is not inserted into another app.

## Running in the background

Closing main hides it. Tray Open Texpio restores it; Quit exits. Launching again restores the existing instance. Tray controls can pause/stop the probe while hidden. Restart/install requires confirmed probe shutdown.

## Diagnostics, notifications and updates

Developer can request a test notification; OS settings affect delivery. A rendering failure offers redacted diagnostic saving and safe restart, reporting actual save success/failure.

Check for Updates is manual. This preview has no configured feed/key and reports setup unavailable. Future configured builds ask before download/install and allow cancellation before installation.

## Experimental expansion

Developer starts Stopped. Fixed snippets/controls support a separate qualification campaign. Physical typing evidence remains incomplete; clipboard and picker insertion are not qualified. Closing the window does not quit the app.
