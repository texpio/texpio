# Using the adopted template

Texpio began with the official Tauri starter, then adopted the full dannysmith shell at revision `1295f691bbdf373896e7c0f1cc969e2040fbf42c`. Product identity, history, approved plans and guarded engine are preserved.

Use Bun 1.4.4, Node 24.18.0 and Rust 1.99.1. Follow [setup](development.md), frozen install, `bun run check:all`, then `bun run tauri:dev`. Home provides the shell; Developer preserves the experimental probe. Ordinary development does not arm it.

[Portable skills and roles](../.agents/README.md) replace source Claude-specific storage. Discovery/registration varies by runtime. Initialization does not run again for unrelated work. Signing/feed setup, native macOS/Linux qualification and physical expansion trials remain separate gates. Accounts/billing/sync belong to the future separate backend.
