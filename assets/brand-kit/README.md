# Texpio brand toolkit

Start with `brand-guide.html` for the identity, palette, typography, usage examples and contrast guidance. Keep the guide and its folders together after extracting the ZIP.

## Files

- `logos/`: horizontal and stacked logo lockups in full color for light and dark backgrounds, and single-color ink and white versions; independent icon and wordmark SVGs; transparent PNG exports. `icon-master-10-percent.svg` is the selected original-canvas master with the connected-dot element reduced by 10%. The wordmark is outlined, so the core logo SVGs do not depend on an installed font.
- `icons/`: square rounded app icon and padded square social avatar in SVG and PNG; SVG, PNG and multi-size ICO favicons. The avatar includes padding for circular profile crops. Test the favicon on the backgrounds where it will appear.
- `social/`: editable SVG social cover (1500 × 500) and announcement graphic (1200 × 1200), with PNG previews. Text is editable; the wordmark is outlined. Install the included Poppins fonts if the editor cannot resolve the local font reference. Actual social-platform crops vary, so preview each placement.
- `fonts/`: Poppins Regular, Medium, SemiBold and Bold and their SIL Open Font License. The fonts are redistributed under that license; keep the license with them.

## Using the artwork

Choose `color-light` on pale backgrounds and `color-dark` on dark backgrounds. Use `mono-ink` or `mono-white` when a single color is needed. Preserve aspect ratios. For more sizes, export from the SVG master using a vector editor. Transparent PNG files may look invisible or appear against a black preview background in some image viewers; place them on a suitable surface.

The app and social icons have intentional background shapes. Favicon SVG/PNG files are transparent and ink colored. Social graphics contain sample copy, not a launch announcement; revise it to match verified product capabilities. This package does not modify your website, app, or existing brand files.

## Palette

Ink `#172B32` · Mint `#67DDB4` · Forest `#08765E` · Paper `#F7F8F2` · Slate `#576B6B`

Use forest rather than light mint for small text on paper; see the guide for tested contrast ratios and minimum size recommendations.
