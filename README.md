# Texpio

A proposed open-source, local-first text expander for Windows, followed by macOS. Create and reuse text locally, with optional paid managed sync later.

The user selected **Texpio** on 23 October 2026. This workspace currently contains product-planning documents; the application has not been implemented. Tauri with a separate Rust expansion engine is the recommended direction to validate.
